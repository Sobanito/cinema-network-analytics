# Cinema Network Analytics

## Project overview

This is an ongoing data analytics portfolio project developed as part of my SQL and Business Intelligence learning journey.

The project uses a fictional cinema network database to explore relational database design, data preparation, SQL querying and business-oriented analysis.

## Technologies
- PostgreSQL
- SQL
- pgAdmin 4

## Current scope
- Relational database design
- Tables for cinemas, cinema halls, seats, movies and screenings
- Basic SQL queries and data manipulation

## Planned development
- Data quality checks and cleaning
- Exploratory data analysis
- Business performance reporting
- Advanced SQL queries
- Data visualizations

## Project status
Work in progress — educational project using fictional data.
